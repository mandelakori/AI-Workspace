# Deterministic editor recovery evidence

No model inference or remote dispatch. `replay/` contains the 37 saved-argument
receipts and 11 applied disposable source copies (only two distinct source
hashes); these are not feature candidates. Original inputs are read-only at
`../a100-duration-trial-result/attempt/mcp.jsonl` and
`../milestone-e-a100/itsdangerous-pinned-source.zip`. ItsDangerous source is
covered by [the preserved BSD license](../milestone-e-a100/ITS-DANGEROUS-LICENSE.txt).

`harness/` records two installed OpenCode/MCP runs against an inert scripted HTTP
provider. It retains forwarded catalogs/arguments, synthetic responses, source
inspection records, edits, recovery counters, public checks, context accounting,
cleanup and normalized receipts. No real inference tokens were generated.
`result.json` preserves the raw harness trace as well as its result; controller
receipts remain distinct from the test's independent assertions.

`verification.json`, regression logs and `preservation.json` record the final
verification. `evidence-hashes.json` covers all files here except itself.
